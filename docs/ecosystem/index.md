# The LPJ-EOSIM ecosystem

Below is a SVG that describes the LPJ-EOSIM ecosystem as of October 2026. This
is part of the push to enable fast and reproducible science. With the advent of
CLI coding tools, upgrading workflows into containerized, robust, and
monitorable packages has never been easier, so the LPJ-EOSIM team is taking advantage!

We've been able to add many different processes to the model, including a new
fire module, an interactive nitrogen cycle, and (upcoming) a new model of
methane emissions.
