int iterate(FILE **output, Cell *grid, Climate *climate, Landuse *landuse, const Pftpar *pftpar, int npft, int ncft, int ntypes, Config config)¶

probe

Entrypoint into LPJ. Runs the iterateyear routine for each year using a for loop. The for loop (corresponding to the number of years to run) starts in the first year of the simulation (config.firstyear) minus the number of spinup years (config.nspinup), and proceeds to config.lastyear. Throughout the LPJ codebase the shorthand config.firstyear == config.lastyear is used to check if the current run is a spinup run.

void update_stand_outputs_annual(Output *output, const Stand *stand)¶

Snapshot one stand’s annual state into the by-stand banded outputs.

Called for every stand from the snapshot loop at the end of update_annual (just before total_carbon), so it sees the same stand set as fwriteoutput_annual. Accumulates (+=) so multiple stands of one landusetype (e.g. age classes) sum into their type’s band; the caller zeroes the arrays first. Pool sets mirror fwriteoutput_annual’s cell totals so bands sum to the cell total. Band index == landusetype code (stand_output_slot); works with and without AGECLASS builds since age-class stands keep landusetype PRIMARY/SECFOREST.

void update_stand_outputs_daily(Output *output, const Stand *stand, Real dgpp, Real dnpp, Real drh)¶

Log the day’s stand-level fluxes into the by-stand banded outputs.

Called once at the very end of the daily foreachstand loop body, where drh is valid in both the NITROGEN (soil_dynamics_century) and non-NITROGEN (littersom) paths. All inputs must already be weighted by stand->frac; band index == landusetype code (stand_output_slot).

Calculation of Net Downward Short-Wave Radiation Flux¶

(also known as insolation or incident solar radiation)

\[(1)\quad rs = (c + d \cdot ni) \cdot (1 - \beta) \cdot Q_0 \cdot \cos Z \cdot k \]

\[(2)\quad Q_0 = Q_{00} \left( 1 + 2 \cdot 0.01675 \cdot \cos \left(\frac{2 \pi i}{365}\right) \right) \]

\[(3)\quad \cos Z = \sin(\mathrm{lat}) \cdot \sin(\delta) + \cos(\mathrm{lat}) \cdot \cos(\delta) \cdot \cos h \]

\[(4)\quad \delta = -23.4 \cdot \frac{\pi}{180} \cdot \cos \left(\frac{2 \pi (i+10)}{365}\right) \]

\[(5)\quad h = \frac{\pi t}{12} \]

Variable definitions:¶

  • rs — instantaneous net downward shortwave radiation flux (W/m² = J/m²/s)

  • c, d — empirical constants (c+d = clear sky transmissivity)

  • ni — proportion of bright sunshine

  • beta — global shortwave albedo

  • i — Julian date (1–365, 1 = Jan 1)

  • Q00 — solar constant (1360 W/m²)

  • Z — solar zenith angle

  • k — conversion factor from solar angular units to seconds (12/π × 3600)

  • lat — latitude (radians)

  • delta — solar declination angle

  • h — hour angle

  • t — local time (hours from solar noon)

Daily Integration¶

\[(6)\quad rs = (c + d \cdot ni)(1 - \beta) Q_0 \left[ \sin(\mathrm{lat})\sin(\delta) + \cos(\mathrm{lat})\cos(\delta)\cos h \right] k \]

Sunrise/sunset: \( Z = \pm \frac{\pi}{2} \) → \( \cos Z = 0 \).

\[(8)\quad \cos h_h = - \frac{\sin(\mathrm{lat}) \sin(\delta)}{\cos(\mathrm{lat}) \cos(\delta)} \]

Define:

\[(9)\quad u = \sin(\mathrm{lat}) \sin(\delta) \qquad (10)\quad v = \cos(\mathrm{lat}) \cos(\delta) \]

\[(11)\quad h_h = \arccos \left( -\frac{u}{v} \right) \]

Net daily downward short-wave radiation flux:

\[(12)\quad rs_{day} = 2 (c + d \cdot ni) (1 - \beta) Q_0 (u h_h + v \sin h_h) k \]

Define:

\[(13)\quad w = (c + d \cdot ni) (1 - \beta) Q_0 \]

Final:

\[(14)\quad rs_{day} = 2 w (u h_h + v \sin h_h) k \]

static Real lloyd_taylor_response(Real temp)¶

Original temperature response function for both soil and plant respiration. This function is used by default in all LPJ-EOSIM TRENDY simulations. Other respiration options are available through the RESP_OPT flag, but are experimental and therefore undocumented. Based on Eqn 11, Lloyd & Taylor (1994):

\[g(T) = \exp \left[ 308.56 \left( \frac{1}{56.02} - \frac{1}{T - 227.13} \right) \right] \]

where \( T \) is temperature in Kelvin.
