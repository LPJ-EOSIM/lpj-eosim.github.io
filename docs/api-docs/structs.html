LPJ-EOSIM structs¶

Structs are named sets of values that occupy a contiguous block of memory. Useful for grouping related concepts together (e.g., a Config struct, a PFT struct). This page contains descriptions of important structs in the codebase

group LPJ-EOSIM structs
struct Climbuf¶
#include <climate.h>

Struct containing growing degree days, the previous 31 days of temperature, the previous 32 days of daily precipitation, and min/max/mean temperature records.

struct Config¶
#include <config.h>

Main configuration structure.

This struct is populated in fscanconfig.c and contains references to driver and restart filenames as well as a list of output filenames. It also stores core simulation parameters such as grid dimensions and years.
